
**FPV Drones**

This repository contains the Betaflight configurations for my FPV drones, including both original factory configurations and my current custom setups.

For each drone, you will typically find:

* diff all files
* Full dump files
* Screenshots of key Betaflight settings (rates, ports, etc.)

The repository serves both as a backup archive and as a reference for comparing configurations across different aircraft.

Notes

* Configurations may evolve over time as tuning, rates, filters, and features are updated.
* Both stock and modified configurations are preserved whenever possible.
